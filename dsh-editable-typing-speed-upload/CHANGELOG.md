# Changelog

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 0.4.3 — 2026-11-13

**降本 + 持久化**（用户反馈挂机后余额被吃光，查明是长会话 + 转译每块都翻译）：

- 转译**每条回复只调一次模型**：只翻译最后一段正文，中间旁白/工具前导不翻译（之前每个文本块各发一次请求）。代价是该回复要整条生成完才出现。
- `/coding` 的编码模式**持久化**到配置（`prompt.codingSessions`）：插件重装/重启后按名单自动重新挂上会话级遮蔽，不再需要重新输入。
- 测试 32 个。

## 0.4.2 — 2026-11-13

**「完整输出」**：文本加工从前移到**模型输出流**（`llm/stream` 瀑布）上，所以 Web GUI 与 QQ 看到的是同一份处理结果，消息落库时就是最终文本。

- 转译（英文原文→中文）现在 Web 里也生效；之前只有 QQ 出站会译。
- 只留对话、颜文字也在这一层做，不再依赖 IM 适配器。
- 代价：被加工的文本块必须等整块出来再翻译，所以这些回合的文字会「一次性出现」，不是逐字流。
- 内部翻译请求带标记，避免被自己的瀑布再次拦截造成递归。
- 新增 5 个流处理用例，共 31 个测试。

## 0.4.1 — 2026-11-13

- 命令名改用宿主允许的 ascii 名：`/coding`（编码模式）与 `/persona`（拟人模式）。宿主命令名正则 `^[a-z][a-z0-9_-]*$` 会拒绝中文名，原先注册 `/编码模式` 失败。

## 0.4.0 — 2026-11-13

**新增文本处理**（纯文本，不花 token）：只留对话（去旁白/动作/引号）、每 2–3 句加颜文字、拆称呼（句首称呼单独成条）、让模型用 `---` 自己判别拆不拆。

**新增写作风格**（注入系统提示，全局生效）：转译（原文英文→发送前译回中文）、文言、文言转译、回答简短。转译会多一次 LLM 调用，token 翻倍，面板上有警告。想临时让某个会话不受影响，在该会话发 `/编码模式`；`/拟人模式` 恢复（拿不到会话作用域时退化为全局开关）。

**配置结构**：`split.auto` / `split.vocative`、`text.dialogOnly` / `text.emoticon`、`prompt.style` / `prompt.shortAnswers` / `prompt.codingMode`；旧的 `split.shortReplies` 移除（它当时被误当成拆条开关，实际是写作提示）。

测试 26 个用例。

## 0.3.0 — 2026-11-13

**随机的位置改了（语义变更）**：以前是「整体延迟在 min–max 之间随机」，现在是「**阅读速度 / 打字速度各自在区间内随机**」，时间由字数折算出来；`baseMs`（反应时间 / 基础停顿）是固定值，不参与随机。

- `readDelay` / `segmentGap` 的参数换成 `baseMs` + `minCharsPerSecond` / `maxCharsPerSecond`。
- 旧配置自动迁移：旧 `minMs` → `baseMs`，旧 `charsPerSecond` → 其 0.6x–1.4x 作为速度区间；不需要手动改配置文件。
- 面板同步：反应时间（秒）、阅读速度下限/上限（字/秒）、基础停顿（秒）、打字速度下限/上限（字/秒）。
- 三档预设按新模型重写；`/pacing` 状态文案改为显示速度区间。
- 测试更新到 21 个用例，含旧配置迁移。

## 0.2.3 — 2026-11-13

- 面板上的时间一律用**秒**，支持小数（0.1 秒步进，可手填 1.25）：随机区间、单回合封顶、单次封顶都不再显示毫秒。配置里仍然是毫秒，只在界面换算。
- 「下限 / 上限」改成「随机区间下限 / 随机区间上限」，避免看不懂指的是什么。

## 0.2.2 — 2026-11-13

- **设置面板换到更好找的入口**：除了行级页面（`plugins.row.config`，要点进「包含的组件」里那一行的 `›` 才看得到），现在同时注册 `plugins.bundle.config` —— 打开插件详情页就能直接看到表单，不用再点一层。
- 「拆条」分区改名为「拆条 / 换行」，说明里点明这是把一条回复拆成多条消息分开发的开关。

## 0.2.1 — 2026-11-12

- **修复冷启动时 HTTP 接口与 `/pacing` 命令可能缺失**：插件 apply 可能早于宿主 `webServer` / `commands` 服务就绪，之前直接跳过注册就再也不补了。现在路由与命令也由 5 秒自愈探针接管——谁先出现就先挂上，挂过不重复。
- 发布包改为从 tarball 安装验证（真实复制安装，非目录链接），确认 `lib/`、`client.js`、`locale/`、`cordis.patch.yml`、`icon.svg`、`index.json` 等运行时文件齐全。

## 0.2.0 — 2026-11-11

- **改名**：`dsh-im-pacing` → `dsh-editable-typing-speed`（包名、插件行 id、HTTP 路由、客户端注册键同步更新）。npm 与 npmmirror 上该名称均未被占用。
- **新增设置面板**：注册到 `plugins.row.config`，插件页该行出现「配置」入口；可调总开关、QQ 渠道开关、读延迟、段间隔、拆条，并内置三档预设（轻拟人 / 慢性子 / 即刻应答）。
- **新增**：`AI-DECLARATION.md`（AI 参与范围与责任划分）、`PUBLISHING.md`（首次发布 GitHub / npm 操作指南）。
- **修复**：
  - 新旧插件世代竞态：改配置重启时，旧一代的清理可能关掉新一代的节奏；改为「一代一票」。
  - `/status` 读到过期配置：改为读共享 `runtime.current`。
  - 自愈探针每 5 秒重复解析 SDK：加模块缓存。
  - `msg_seq` 为字符串时不递增，拆条会让多条共用同一序号：改为数值化再递增。
- **测试**：新增宿主生命周期用例，共 20 个。
